## 一、项目背景与研究主旨
本项目旨在为福建泉州「市井十洲城」落地策划的「番货市集」大型慢闪商业文化项目提供深度田野考据与视觉设计素材支撑。通过深度搜集东南亚十一国（马、泰、越、印尼、新、菲、柬、老、缅、文、东帝汶）代表性城市、古都与族群的文化风物、历史建筑、民间手工艺与市井日常生活器物，建立高审美价值、高可信度且便于检索的视觉资料库。

---

## 二、资料库核心规模
- **覆盖国度**：**11 / 11 东南亚全域国家 100% 覆盖**
  - 马来西亚 (MY: 18项)、泰国 (TH: 13项)、越南 (VN: 12项)、印度尼西亚 (ID: 12项)
  - 新加坡 (SG: 5项)、菲律宾 (PH: 5项)、柬埔寨 (KH: 3项)、缅甸 (MM: 3项)
  - 文莱 (BN: 2项)、东帝汶 (TL: 2项)、老挝 (LA: 1项)
- **风物条目总数**：**76 项** 真实可核验文化视觉要素
- **高清图源归档**：**142 张** 真实摄影大图（整体造型、局部肌理、真实使用场景）
- **核验标准**：100% 原始考据落盘，遵循 Creative Commons 知识共享与维基学术引证规范。

## 四、技术与策展特性
1. **美术馆策展风格排版**：高对比度古典衬线宋体标题、展签卡片相框式装裱、沉浸式文献档案弹窗。
2. **纯前端零依赖**：无任何第三方 CDN 框架依赖，通过 `<script src="data.js">` 引入数据，彻底规避 CORS 与离线浏览限制。
3. **空间场景与国度索引**：支持按 11 国独立筛选，卡片自带全幅标准填充（Cover）与原图完整比例呈现。
