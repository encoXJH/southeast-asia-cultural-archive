# 05｜民间工艺与传统器物 - 菲律宾

本文件记录菲律宾在【05｜民间工艺与传统器物】类别的精选真实文化风物与视觉设计素材条目。

## PH-05-0001 菲律宾传统卡皮斯海月贝壳百叶窗（Capiz Windows）

- 中文名称：菲律宾传统卡皮斯海月贝壳百叶窗（Capiz Windows）
- 英文名称：Philippine Traditional Capiz Shell Grid Windows
- 当地名称（原文）：Bintanang Kapis / Capiz window
- 当地名称（罗马转写）：—
- 国家：菲律宾
- 城市/地区：全菲（以米沙鄢群岛及卡皮斯省为代表）
- 类别：05｜民间工艺与传统器物
- 族群/文化传统：西属殖民时期南洋海月贝壳采光手艺、热带民居抗风透光构件

### 文化介绍
卡皮斯贝壳窗（Capiz Windows）是菲律宾殖民时期建筑最具地域辨识度的材质符号。在平板玻璃尚未普及或价格昂贵的17至19世纪，群岛工匠就地取材，利用盛产于卡皮斯省浅海的天然海月贝（Placuna placenta）扁平坚硬的贝壳外壳。经浸泡酸洗去杂质后，切削成约6至8厘米见方的正方形贝壳薄片，镶嵌在优质硬木条十字交错构成的窗格网格之中。贝壳天然半透明，不仅能完全阻挡热带炫目强烈的紫外线与暴雨狂风，还能将刺眼的户外直射日光漫射转化为如乳白珍珠般的温柔室内散射柔光，兼具惊人抗震韧性与自然珍珠母光泽。

### 视觉特征
- 造型：推拉滑动式木框窗扇（Sliding sashes），内部细木格划分成数十至上百个均匀正方形贝壳单元方格。
- 色彩：半透明乳白色底色，逆光时呈现柔和微光，侧光时泛出天然珍珠母（Mother-of-pearl）贝壳独特的彩虹幻彩色泽。
- 材质：天然海月贝壳角片（Capiz Shell）、耐腐红木/柚木框架窗棂、黄铜滑轨与插销。
- 图案：严密匀称的笛卡尔直角正方形网格律动；贝壳表面天然同心生长轮弧线与微弱凹凸天然纹理。
- 空间形态：往往成排贯通整个建筑立面外廊，整座窗面拉开时完全开敞吹风，闭合时在室内地面洒下棋盘格般的斑驳柔光网格。
- 视觉辨识度：与西方彩色铅嵌玻璃或东方白棉纸窗格截然不同，卡皮斯贝壳不怕热带暴雨冲刷与潮湿海风腐蚀，散发着独特的海洋生物质感与珍珠冷光。
