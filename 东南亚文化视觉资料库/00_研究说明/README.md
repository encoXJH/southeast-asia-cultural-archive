# 东南亚十一国文化风物与视觉素材数据库

## 一、项目背景
本项目服务于落地于福建泉州「市井十洲城」的三个月慢闪商业文化项目「番货市集」。
项目以东南亚各国的地方文化、城市生活、传统工艺、民间艺术、特色商品和独特景观为素材，开展主题策展、商业空间设计、艺术装置创作、特色商铺陈列、公共空间营造及文化活动。

## 二、核心原则与核验底线
1. **真实性 > 地区深度 > 数量**：严禁任何虚构内容与臆造链接。
2. **实际访问来源原则**：仅收录会话中实际检索、访问并核验过的图片链接与资料源。
3. **增量落盘与断点续作**：每完成一个类别或每批次更新即时同步至 Markdown 条目、总索引（CSV）、图库数据（data.js）及进度文档（progress.md）。
4. **图片三级 Fallback**：
   - A级·已下载：本地保存高质量图片并记录来源与授权。
   - B级·仅链接：标注未下载并保留原始权威直链。
   - C级·无图待补：保留详实考据文字，如实标记待补图。

## 三、目录体系
- `00_研究说明/`：规范、模板、分类定义
- `01_马来西亚/` ~ `11_东帝汶/`：各国 15 个类别的深度文化条目 Markdown
- `12_图片素材库/`：规范归档本地图片（格式：`[国家代码]/[类别编号]/[素材ID]_[序号].[ext]`）
- `13_文化元素总索引/`：`index.csv` 结构化总表
- `14_HTML可视化图库/`：`index.html` + `data.js` 无依赖本地图库
- `15_研究进度与来源/`：`progress.md` 跨会话断点续作进度追踪表
